# SilverMeter – silver rate website

https://silvermeter.in

Shows today's silver rate in India and tells visitors whether it is **cheaper or costlier than usual** compared with recent days (the "Buy-o-Meter" design). Plain HTML/CSS/JS generated by a tiny Node script with no dependencies, hosted free on **Cloudflare** (Workers static assets).

## Pages

| URL | What it shows |
|---|---|
| `/` | Today's India rate, meter, 30-day chart, calculator, today vs yesterday, FAQ |
| `/silver-rate-today-<city>/` | Same for each city in `data/rates.json` (created automatically) |
| `/silver-price-calculator/` | Jewellery price with purity, making charge and 3% GST |
| `/silver-rate-history/` | Daily and monthly history per location |
| `/about/`, `/data-source/`, `/disclaimer/`, `/privacy-policy/` | Trust and policy pages (needed for AdSense) |
| `/contact/` | Only built when `contactEmail` is set |

SEO built in: unique titles and descriptions, canonical URLs on `https://silvermeter.in`, Open Graph and Twitter tags, JSON-LD (WebSite, FAQPage, BreadcrumbList, Dataset, WebApplication), `sitemap.xml` and `robots.txt` at the domain root, `ads.txt` (when AdSense is set), rates rendered into the HTML, security and cache headers (`src/_headers`), fast pages with no external fonts or frameworks, accessible markup. `scripts/check.mjs` fails the build if any page has a broken link, a missing tag or a duplicate title.

## How deploys work

- Cloudflare **Workers Builds** watches this repo. Every push to `main` runs `node scripts/build.mjs && node scripts/check.mjs` and deploys `dist/` with `npx wrangler deploy` (config: `wrangler.jsonc`).
- `.github/workflows/update-rates.yml` runs daily at 09:45 IST: it fetches today's rate (if the `RATE_API_URL` secret is set), commits `data/rates.json`, and that push triggers a Cloudflare deploy.

### Cloudflare setup (one time)

1. Cloudflare dashboard → **Add a domain** → `silvermeter.in` → Free plan. Copy the two Cloudflare nameservers and set them at your domain registrar (replace the registrar's default nameservers).
2. **Workers & Pages → Create → Import a repository** → connect GitHub → choose `silver-website`.
   - Build command: `node scripts/build.mjs && node scripts/check.mjs`
   - Deploy command: `npx wrangler deploy` (default)
3. In the Worker → **Settings → Domains & Routes → Add → Custom domain**: add `silvermeter.in` and `www.silvermeter.in`.
4. **Rules → Redirect Rules** → template "Redirect from WWW to root": `www.silvermeter.in/*` → `https://silvermeter.in/${1}`, 301.
5. SSL/TLS → Edge Certificates → turn on **Always Use HTTPS**.
6. GitHub repo → Settings → Pages → **Unpublish / disable** the old `github.io` site, so Google does not see duplicate copies.

## Before launch

1. **Real rate data (MetalCharts).** Rates come from the [MetalCharts](https://metalcharts.org) API (free plan, commercial use allowed): the international silver spot price in INR plus India's import duty (`importDutyPct` in `data/rates.json`, currently 15% = 10% BCD + 5% AIDC) gives an **estimated India rate before 3% GST**. Setup:
   - Create a free MetalCharts account → API console → create a key.
   - GitHub repo → Settings → Secrets and variables → Actions → New repository secret: `METALCHARTS_API_KEY`.
   - Actions → "Update silver rates" → Run workflow. The first run replaces the sample data with the last ~30 days of real prices, turns off the Preview banner and `noindex`, and commits to `main`; Cloudflare deploys it. After that it runs daily at 09:45 IST (about 31 API calls a month, within the free 200).
   - If the import duty changes, update `importDutyPct` and run the workflow with "backfill" ticked.
2. **Add cities:** add an entry under `locations` in `data/rates.json`. A city page, sitemap entry and "Meter by city" tile appear automatically.
3. **Settings in `site.config.json`:** `contactEmail` (builds the Contact page; Cloudflare Email Routing can forward `contact@silvermeter.in` to your inbox for free), `whatsappChannelUrl`, `adsenseClientId` (adds AdSense auto ads, `ads.txt`, and updates the privacy policy), `googleSiteVerification`.
4. **Google Search Console:** add `silvermeter.in` (Domain property, verify via a Cloudflare DNS TXT record) and submit `https://silvermeter.in/sitemap.xml`.

## Run locally

```bash
node scripts/build.mjs   # writes dist/
node scripts/check.mjs   # SEO + link checks
cd dist && python3 -m http.server 8000   # open http://localhost:8000
```
