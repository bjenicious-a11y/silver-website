# SilverMeter – silver rate website

Shows today's silver rate in India and tells visitors whether it is **cheaper or costlier than usual** compared with recent days (the "Buy-o-Meter" design). Plain HTML/CSS/JS generated by a tiny Node script, with no dependencies, hosted free on GitHub Pages.

Live (after Pages is enabled): https://bjenicious-a11y.github.io/silver-website/

## Pages

| URL | What it shows |
|---|---|
| `/` | Today's India rate, meter, 30-day chart, calculator, today vs yesterday, FAQ |
| `/silver-rate-today-<city>/` | Same for each city in `data/rates.json` (created automatically) |
| `/silver-price-calculator/` | Jewellery price with purity, making charge and 3% GST |
| `/silver-rate-history/` | Daily and monthly history per location |
| `/about/`, `/data-source/`, `/disclaimer/`, `/privacy-policy/` | Trust and policy pages (needed for AdSense) |
| `/contact/` | Only built when `contactEmail` is set |

SEO built in: unique titles and descriptions, canonical URLs, Open Graph and Twitter tags, JSON-LD (WebSite, FAQPage, BreadcrumbList, Dataset, WebApplication), `sitemap.xml`, rates rendered into the HTML (not loaded by JavaScript), fast pages with no external fonts or frameworks, accessible markup. `scripts/check.mjs` blocks a deploy if any page has a broken link, a missing tag, or a duplicate title.

## Before launch: important

1. **Turn on GitHub Pages:** Repo → Settings → Pages → Build and deployment → Source: **GitHub Actions**. The workflow then deploys on every push.
2. **Real rate data.** `data/rates.json` currently holds **sample data** (`"sample": true`). While it's set, every page shows a "Preview" banner and has `noindex`, so Google does not index sample prices. When you have a real source:
   - either edit `data/rates.json` yourself each morning (GitHub web editor works), or
   - add repo secrets `RATE_API_URL` (+ optional `RATE_API_KEY`, `RATE_SOURCE_NAME`, `RATE_SOURCE_URL`) and the workflow fetches the rate daily at 09:45 IST. See `scripts/update-rates.mjs` for the expected JSON.
   - then set `"sample": false` and the correct `sourceName` / `sourceUrl`. Make sure your data source allows republishing.
3. **Add cities:** add an entry under `locations` in `data/rates.json` (e.g. `"salem": { "name": "Salem", "history": [...] }`). A city page, sitemap entry and "Meter by city" tile appear automatically.
4. **Custom domain (recommended).** On a `github.io/silver-website` URL, Google only reads `robots.txt` and `ads.txt` at the domain root, so AdSense `ads.txt` cannot work there. Buy a domain, add it in Settings → Pages, then change `baseUrl` in `site.config.json`.
5. **Settings in `site.config.json`:** `contactEmail` (builds the Contact page), `whatsappChannelUrl` (shows the alerts box), `adsenseClientId` (adds AdSense auto ads and updates the privacy policy), `googleSiteVerification` (Search Console).

## Run locally

```bash
node scripts/build.mjs   # writes dist/
node scripts/check.mjs   # SEO + link checks
cd dist && python3 -m http.server 8000
```

Note: links include the `/silver-website` base path, so for local preview serve a parent folder that contains `dist` as `silver-website`.
